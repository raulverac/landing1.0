¿Qué es LandingBuilder?

LandingBuilder es una herramienta web que permite crear landing pages profesionales de forma visual, sin necesidad de escribir código. El resultado es un archivo HTML listo para publicar en cualquier servidor o plataforma.

🎨

Editor visual en tiempo real

Cada cambio que realizas en el panel izquierdo se refleja instantáneamente en la vista previa derecha.

📐

6 estructuras prediseñadas

Plantillas optimizadas para distintos objetivos: ventas, beneficios, urgencia, storytelling y más.

📋

Formularios configurables

Define campos, posición (hero o footer) y estilos. También soporta embed de código externo.

🔗

Parámetros UTM integrados

Configura UTMs una sola vez y se aplican automáticamente a todos los enlaces de la landing.

📱

Responsive con Bootstrap

El HTML exportado incluye Bootstrap 5.3 para visualización correcta en móviles y tablets.

💾

Gestión de landings

Guarda múltiples landings en el navegador, edítalas, duplícalas o descárgalas cuando necesites.

💡
Sin instalación adicional

LandingBuilder funciona completamente en el navegador. El archivo HTML exportado incluye todo lo necesario (Bootstrap CDN, estilos, JavaScript) para funcionar de forma independiente.

Crear una Landing Paso a Paso

1
Elegir estructura

Al entrar a la aplicación se muestra la página "Estructura". Haz clic en la plantilla que mejor se adapte a tu objetivo. Verás un wireframe animado de cada opción. Presiona "Usar esta estructura y editar →".

2
Nombrar la landing

En el panel editor, el primer campo es el Nombre de la Landing. Escribe un nombre descriptivo (ej: "Campaña Enero 2026 - Producto X"). Este nombre aparecerá en "Mis Landings" y como título del archivo HTML.

3
Configurar el Header

En la pestaña Header define el logo (texto o imagen), tamaño del logo, colores de fondo y texto, y los ítems del menú de navegación.

4
Configurar el Hero

En la pestaña Hero carga hasta 3 imágenes para el carrusel, escribe el título, descripción y botón de llamada a la acción. Ajusta el overlay oscuro con el slider.

5
Editar el contenido central

La pestaña de contenido varía según la estructura (Servicios, Beneficios, Urgencia, etc.). Agrega, edita o elimina tarjetas de contenido.

6
Configurar el Formulario

En la pestaña Formulario define el tipo (básico o embed), campos, y posición (Hero y/o Footer). Personaliza colores y botón.

7
Agregar UTMs (opcional)

En la pestaña UTM llena source, medium, campaign, content y term. Se aplicarán a todos los enlaces de la landing automáticamente.

8
Guardar y exportar

Usa "Guardar" para guardar en "Mis Landings" y "↓ HTML" para descargar el archivo listo para publicar.

✅
Tip de productividad

Puedes guardar en cualquier momento con el botón "Guardar" y seguir editando. Los cambios guardados se mantienen aunque cierres el navegador.

5

Pestaña Header

El header es la barra de navegación superior que aparece fija en todas las páginas de la landing.

Panel: Logo y Colores

CampoDescripción
Texto del LogoNombre de la marca que aparece si no hay imagen de logo. Se muestra en la barra superior.
Logo (URL o subir imagen)Sube una imagen desde tu dispositivo o pega una URL externa. Formatos: PNG, JPG, SVG, WebP. Si hay logo, oculta el texto del logo.
Tamaño del logoSlider de 16px a 120px. Controla el alto de la imagen del logo en el header.
Color de fondoColor del header. Incluye control de opacidad (slider 0–100%).
Color de textoColor del logo-texto y de los ítems del menú.

Panel: Menú de Navegación

Define los ítems del menú superior. Cada ítem tiene:

  • Etiqueta: El texto visible del enlace (ej: "Servicios")
  • Enlace: El destino. Usa #seccion para anclas internas o URLs completas.

Usa el botón "+ Agregar ítem" para añadir nuevas entradas y el botón ✕ para eliminar.

💡
Selector de color con opacidad

Todos los selectores de color del editor incluyen un slider de opacidad debajo del color. Al reducir la opacidad, el valor se guarda como rgba(r,g,b,alpha). Esto es útil para headers semitransparentes sobre imágenes.

6

Pestaña Hero

El Hero es la sección principal de impacto visual, generalmente lo primero que ve el visitante. Incluye carrusel de imágenes, título, descripción y llamada a la acción.

Panel: Carrusel — 3 Slides

Puedes cargar hasta 3 imágenes para el carrusel automático del hero:

  • Las imágenes rotan automáticamente cada 3.5 segundos en el HTML exportado.
  • Slide 1 siempre visible por defecto.
  • Puedes subir imagen desde tu dispositivo o pegar una URL.
  • Si solo usas 1 imagen, no habrá carrusel (imagen fija).
  • La imagen del Slide 1 también se usa como fondo en la estructura UNAB.

Panel: Texto y Botón

CampoDescripción
Título PrincipalEncabezado principal del hero. Texto grande y de impacto.
DescripciónPárrafo de apoyo al título. Máximo 2-3 líneas recomendado.
Texto del BotónTexto de la llamada a la acción (CTA), ej: "Contáctanos ahora".
Enlace del BotónURL o ancla adonde lleva el botón CTA.
Color del BotónColor de fondo del botón CTA. Con control de opacidad.
Overlay oscuroSlider 0–100%. Controla la oscuridad del velo sobre las imágenes para mejorar legibilidad del texto.
ℹ️
Formulario en el Hero

Si activas "Formulario en Hero" en la pestaña Formulario, el hero cambia a un layout de 2 columnas: texto a la izquierda y formulario a la derecha. Esta opción está disponible en todas las estructuras excepto UNAB.

7

Pestaña Servicios / Contenido Central

Esta pestaña varía su nombre y contenido según la estructura elegida. Permite editar la sección de valor central de la landing.

Clásica y Storytelling — Servicios

Muestra tarjetas con icon, título y descripción. Incluye:

  • Panel Encabezado: Título de sección, subtítulo y colores (fondo, texto, acento).
  • Panel Tarjetas: Lista de servicios/características. Cada tarjeta tiene título y descripción. Puedes agregar o eliminar tarjetas.

Beneficios

Similar a Servicios pero orientado a ventajas competitivas. Cada tarjeta muestra un ícono emoji editable y un rating de estrellas (1–5).

Urgencia

Incluye un contador de cuenta regresiva (automático en el HTML exportado: 2 horas) y una lista de argumentos de valor con íconos.

Profesional — Ecosistema

Sección superior con título, descripción extendida y colores de la empresa/agencia. Incluye color de acento para destacar elementos.

UNAB — Programas

Panel de carreras y programas con categorías (Presencial, Semipresencial, Online). Ver Sección 11 para detalle completo.

💡
Íconos en tarjetas

Los íconos de las tarjetas de servicios y beneficios usan emojis directamente. Pega cualquier emoji desde el teclado (Windows: Win + . / Mac: Cmd + Ctrl + Espacio).

8

Pestaña Formulario

El formulario de contacto o captura de leads es uno de los elementos más importantes de una landing. LandingBuilder ofrece total flexibilidad en su configuración.

Tipo de Formulario

TipoDescripción
BásicoFormulario nativo renderizado por LandingBuilder. Los campos son completamente configurables.
Embed / Código externoPega código HTML de plataformas externas (HubSpot, ActiveCampaign, Typeform, etc.) y se incrustará directamente en la landing.

Posición del Formulario

Con las casillas de verificación puedes controlar dónde aparece el formulario:

  • Formulario en Hero: El formulario aparece a la derecha del Hero, en layout de 2 columnas. El texto e imagen quedan a la izquierda.
  • Formulario en Footer: El formulario aparece antes del footer de la página, en una sección destacada con fondo oscuro.
  • Puedes activar ambas opciones simultáneamente para mostrar el formulario en dos lugares.

Campos del Formulario (tipo Básico)

Cada campo tiene:

PropiedadDescripción
EtiquetaTexto del label visible sobre el campo.
Tipotext · email · tel · textarea
PlaceholderTexto gris de ejemplo dentro del campo vacío.
RequeridoSi está marcado, el campo muestra un asterisco (*) y será obligatorio.

Usa "+ Agregar campo" para nuevos campos y ✕ para eliminar.

Estilos del Formulario

  • Título y Subtítulo: Encabezado dentro del panel del formulario.
  • Texto del Botón: Texto del botón de envío.
  • Color del Botón / Texto del botón: Colores del CTA de envío.
  • Fondo del formulario: Color de fondo del panel completo (con control de opacidad).
  • Color de texto: Color de labels y texto dentro del formulario.
  • Texto de privacidad: Leyenda de política de datos al pie del formulario.
⚠️
Formulario Embed

Al usar código embed externo, el estilo del formulario no se puede controlar desde el editor (lo maneja la plataforma origen). Asegúrate de que el código embed sea compatible con el ancho del contenedor.

Pestaña UTM

Los parámetros UTM permiten rastrear el origen del tráfico en Google Analytics u otras plataformas de analítica web.

Parámetros disponibles

ParámetroDescripciónEjemplo
utm_sourceOrigen del tráficogoogle, facebook, email
utm_mediumCanal de marketingcpc, organic, social
utm_campaignNombre de campañalanzamiento_enero
utm_contentVariante de anunciobanner_azul, video_v2
utm_termKeyword (buscadores)curso+programacion

Comportamiento en el HTML exportado

Los UTMs configurados se añaden automáticamente a todos los enlaces (<a href>) de la landing al exportar el HTML, excepto a las anclas internas (que comienzan con #).

El resultado en la URL final sería:

https://mi-sitio.cl/gracias?utm_source=google&utm_medium=cpc&utm_campaign=lanzamiento_enero
💡
Vista previa de UTM

Al final de la pestaña UTM hay un campo de vista previa que muestra exactamente cómo quedará la cadena de parámetros antes de exportar. Así puedes verificar el resultado final antes de descargar el HTML.

ℹ️
Campos opcionales

Puedes dejar en blanco cualquier parámetro UTM. Solo los campos con valor se incluirán en la URL generada. No es necesario llenar los 5 campos.

Pestaña Footer

El footer es la sección inferior de la landing. Incluye información legal, copyright y puede contener el formulario si se activó esa opción.

Opciones del Footer

CampoDescripción
Nombre de empresaAparece en la sección de información de la empresa dentro del footer.
DescripciónBreve texto descriptivo de la empresa o marca.
CopyrightTexto de derechos de autor al pie (ej: "© 2026 Mi Empresa. Todos los derechos reservados.").
FondoColor de fondo del footer, generalmente oscuro. Con control de opacidad.
TextoColor del texto dentro del footer.
💡
Formulario en Footer

Si activas "Formulario en Footer" en la pestaña Formulario, aparecerá una sección adicional justo encima del footer con el formulario en un panel destacado. Es la posición ideal para capturar leads al final del recorrido de la landing.

Estructura UNAB — Formato Universidad

La estructura UNAB es un formato especializado para instituciones educativas. Tiene un layout único que no sigue la lógica estándar de las otras estructuras.

Layout de la estructura UNAB

🖼️

Hero / Cabecera

La imagen del Slide 1 del Hero cubre toda la estructura como fondo con background-size: cover. El overlay oscuro cubre todo el contenido.

🏛️

Header institucional

Logo de la institución a la izquierda con el título del hero. A la derecha aparece el año de admisión en tipografía grande.

📚

Panel de Programas

Columna izquierda con categorías de carreras (Presencial, Semipresencial, Online) y sus programas listados.

📋

Formulario de postulación

Columna derecha con campos específicos para postulación: RUT, nombres, apellidos, teléfono, email, programa y campus.

Pestaña "Servicios" → Programas

CampoDescripción
Título del HeroTexto principal sobre la imagen de fondo (ej: "Es momento de llegar más lejos").
Label AdmisiónEtiqueta pequeña sobre el año (ej: "Admisión").
Año AdmisiónAño en tipografía grande a la derecha del header (ej: "2026").
Fondo overlayColor de fondo del overlay principal (por defecto azul oscuro semitransparente).
Título del PanelEncabezado del panel de carreras (ej: "Carreras y Programas").
CategoríasCada categoría tiene un nombre y lista de programas. Se pueden agregar y editar.
Texto footer del panelTexto al pie del panel de programas (ej: "+INFO EN MI-SITIO.CL").

Pestaña "Nosotros" → Acreditaciones

Footer de la estructura UNAB con logos de acreditaciones institucionales. Cada acreditación tiene:

  • Texto: Nombre o descripción de la acreditación.
  • Ícono: Símbolo de respaldo si no hay imagen.
  • URL de logo: Imagen del logo de la entidad acreditadora.
ℹ️
Responsive en UNAB

El HTML exportado de la estructura UNAB usa Bootstrap 5.3 con clases col-12 col-md-5 y col-12 col-md-4. En móvil, el panel de programas y el formulario se apilan verticalmente.

Estructura Profesional

La estructura Profesional está diseñada para agencias, empresas B2B y portafolios. Incluye secciones adicionales que no tienen las otras estructuras.

Secciones exclusivas

Ecosistema

Sección de presentación de la empresa con título de bienvenida, descripción extendida y tarjetas de propuesta de valor. Personalizable en colores de fondo y acento.

Catálogo de Servicios

Panel en 2 columnas con hasta N ítems por columna. Cada ítem tiene título y descripción. Útil para listar servicios específicos con más detalle que las tarjetas simples.

Fases / Proceso

Sección que explica el proceso de trabajo en pasos con íconos. Cada fase tiene título, descripción e ícono emoji. Transmite transparencia y metodología.

Formulario en Footer

En la estructura Profesional, el formulario aparece por defecto en el Footer (activado por defecto). El formulario se muestra en 2 columnas: texto a la izquierda, campos a la derecha.

💡
Colores de la estructura Profesional

El hero de la estructura Profesional tiene su propio color de fondo independiente ("Fondo hero") en la pestaña de Ecosistema. Esto permite un hero de color sólido diferente al header.

Guardar y Gestionar Landings

LandingBuilder guarda las landings en el almacenamiento local del navegador (localStorage). Esto significa que estarán disponibles siempre que uses el mismo navegador en el mismo dispositivo.

Acciones disponibles

AcciónCómo hacerloResultado
GuardarBotón "Guardar" en la barra superiorGuarda o actualiza la landing en "Mis Landings"
Ver listaPestaña "Mis Landings" en la barra superiorMuestra todas las landings guardadas
EditarBotón "Editar" en la tarjeta de la landingCarga la landing en el editor
Vista previaBotón "Vista" o hacer clic en la miniaturaAbre la landing en modo pantalla completa
Descargar HTMLBotón "HTML" en la tarjeta o "↓ HTML" en topbarDescarga el archivo HTML listo para publicar
EliminarBotón ✕ en la tarjeta (pide confirmación)Borra permanentemente la landing guardada
⚠️
Precaución con el localStorage

Las landings se guardan en el navegador, no en un servidor. Si limpias el caché o el almacenamiento del navegador, se perderán. Descarga siempre el HTML de las landings importantes como respaldo.

14

Exportar HTML

El archivo HTML exportado es completamente autónomo e incluye:

  • Bootstrap 5.3.3 (CDN) para estilos responsive
  • Todo el contenido y estilos de la landing embebidos
  • JavaScript para el carrusel automático de imágenes
  • JavaScript para el contador de cuenta regresiva (estructura Urgencia)
  • Los parámetros UTM configurados aplicados a todos los enlaces

Cómo publicar el HTML

1
Descarga el HTML

Usa el botón "↓ HTML". El archivo se descargará con el nombre de tu landing (ej: mi-landing.html).

2
Sube el archivo a tu servidor

Via FTP, panel de hosting, o arrástralo a una plataforma como Netlify Drop, GitHub Pages o Cloudflare Pages.

3
Verifica en distintos dispositivos

Prueba en móvil, tablet y escritorio para confirmar que el responsive funciona correctamente.
